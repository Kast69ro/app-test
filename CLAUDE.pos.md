# ActivBank QR — POS-приложение для терминалов Sunmi

Передано от предыдущего дизайнера. Прочитай этот файл перед любой работой.

## Что это
Приложение мерчанта для POS-терминалов Sunmi (P2 / P2 Pro / V2): показ статического
QR «QR рамзи ягона» (стандарт НБТ), сводка платежей за сегодня, история, печать чека
на встроенном принтере. Язык интерфейса — русский, суммы только в TJS (валюту не пишем).

## Главный файл
**`POS Terminal.dc.html`** — единственный источник правды по фронту. Все правки — в нём.
`qr-encode.js` — копия QR-энкодера для справки; рабочая копия ВСТРОЕНА в POS Terminal.dc.html
(внешний import в APK не грузился). Если правишь энкодер — правь в обоих местах.

## Экраны и логика (всё в POS Terminal.dc.html)
1. Вход: телефон +992 → OTP 6 цифр (повтор через 60 с).
2. Установка 4-значного кода доступа. При перезапуске спрашивается только код
   (сессия в localStorage, 5 попыток, затем повторный вход по OTP).
3. Главная: шапка (название терминала, ID мерчанта, лого), карточка QR
   (лого TJ QR | разделитель | «QR рамзи ягона», QR в рамке), тап → полноэкранный QR
   (чистый чёрный, 4 модуля тишины). Плитки: «За сегодня» и «Возврат за сегодня» — без «TJS».
4. История: группировка по дням, pull-to-refresh, карточка операции.
5. Карточка операции: реквизиты, кнопка «Возврат платежа» (СЕЙЧАС ЗАДИЗЕЙБЛЕНА), «Печать чека».
6. Печать: нативный плагин SunmiPrinter (Capacitor). На обычном телефоне — «Принтер не найден».

Демо-режима НЕТ и не добавлять: без сервера вход невозможен (fail-closed, требование банка).

## Бэкенд
База: `http://10.64.20.101:8888` (prop `apiBaseUrl`). Контракт — `docs/pos_api_handoff.md`.
`POST /pos/otp/request`, `POST /pos/otp/verify`, `GET /pos/terminal`,
`GET /pos/summary?date=YYYY-MM-DD`, `GET /pos/history?limit=50&offset=0`.

## Следующая задача — возврат (ждём бэкенд)
Спецификация для бэка: `docs/refund_api_spec.md`. Три точки в UI:
1. Плитка «Возврат за сегодня» — сейчас показывает старый блок cancel (заглушка).
2. Кнопка «Возврат платежа» в карточке — включить, подключить POST refund.
3. Статус «Возврат» / «Возврат в обработке» в истории и карточке.
Открытые вопросы: полный/частичный возврат, подтверждение кодом доступа, чек возврата.

## Сборка APK
`apk/` + `.github/workflows/build-apk.yml` — Capacitor 6, сборка в GitHub Actions.
Порядок обновления: DC → собрать в один самодостаточный HTML (Save as standalone HTML)
→ положить как `apk/www/index.html` → push. Подробности и разбор ошибок — `apk/README.md`.
Печать включается файлом `apk/libs/printerlibrary.aar` (Sunmi SDK), без него — заглушка.

## Стиль
Только инлайн-стили. Шрифты: IBM Plex Mono (цифры/суммы), Lato (блок TJ QR),
системный sans для остального. Фон приложения #F4F4F1, карточки #FFFFFF, бордер #E7E7E2,
текст #16181A / #6B7075. Минимальная зона нажатия 44px.
